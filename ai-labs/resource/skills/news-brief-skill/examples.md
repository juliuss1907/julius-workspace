## Format Notes

### Top Stories Format
- Full narrative (title + summary + source + engagement + link)
- Breaking news tagged with 🔴 BREAKING
- Cross-topic (highest priority regardless of category)
- 2-5 items (flexible based on news quality)

### Dang Doc Format
- Short format (title link + source + engagement)
- Grouped by topic
- 3-5 items per topic (configurable)
- Sorted by priority score within topic

### Source Icons
- 📱 Telegram channels
- 🌐 Websites (thefeed.today, etc.)
- 📰 RSS feeds

### Engagement Display
- Views formatted: 1.2M, 450.0K, 18.3K
- RSS feeds show 👁 0 (no view count available)
