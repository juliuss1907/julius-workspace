# Type Guide — Breakdown (Analysis/Explanation)

**Purpose:** Explain complex topic or analyze situation  
**Best for:** Deep dives, analysis, educational content  
**Length:** 8-15 tweets  
**CT Voice:** Moderate slang (Tier 1+2), selective emoji

---

## Narrative Arc

```
Hook: Bold claim or question + crypto relevance
  ↓
Context: Why this matters to CT
  ↓
Point 1: First key insight
  ↓
Point 2: Second key insight
  ↓
Point 3-N: Additional insights
  ↓
Implication: What this means for crypto
  ↓
CTA: Follow for more analysis
```

---

## Hook Patterns

```

### Pattern C: Data-driven

Thread 🧵👇
```

## CT Voice Calibration

### Slang Usage (Breakdown)

**Frequency:** 2-3 slang terms per thread

**Tier preference:**
- **Tier 1 (frequent):** ser, based, alpha, ngmi, wagmi
- **Tier 2 (occasional):** cope, rekt, rugged, jeet
- **Tier 3 (rare):** midcurve (if explaining takes)

**Placement:**
- Hook: "ser, this is important"
- Body: "this is based" (approval), "pure cope" (criticism)
- Closing: "wagmi if we understand this"

**Breakdown-specific patterns:**

**Analytical slang:**
```
✅ "the data is based"
✅ "this is pure cope, here's why"
✅ "ser, the numbers don't lie"
```

**Avoid casual slang:**
```
❌ "LFG" (too hype for analysis)
❌ "degen mode" (not analytical)
❌ "aped in" (not relevant to analysis)
```

### Emoji Usage (Breakdown)

**Frequency:** 3-5 emojis total

**Breakdown-appropriate emojis:**
- 🧵👇 (hook — mandatory)
- 🧠 (insights/analysis)
- 🎯 (key point)
- 📊 (data)
- 🔬 (research)

**Avoid:**
- 🚀, 🔥 (too hype)
- 🫡, 🤝 (too community-focused)
- Multiple emojis per insight

**Placement:**
- Hook: 🧵👇
- Body: 0-1 per tweet (key insights only)
- Closing: Optional

### Tone (Breakdown)

**Formality:** Casual but informed
```
✅ "Here's what the data shows"
✅ "Most people miss this"
❌ "One must consider" (too formal)
```

**Emotion:** Neutral to skeptical
```
✅ "The evidence suggests X"
✅ "This doesn't add up"
❌ "This is amazing!" (too emotional)
```

**Stance:** Evidence-based
```
✅ "The data doesn't support this claim"
✅ "Based on X, Y is likely"
❌ "I believe X" (opinion without evidence)
```

## Body Structure

### Context tweet (2/N)

Establish why this matters:

```
(2/N) First, some context:

[Background information]

[Why CT should care]

[Stakes or implications]
```

### Insight tweets (3/N to N-2)

One insight per tweet:

```
(X/N) [Transition phrase]

[Main insight — bold statement]

[Supporting evidence or example]

[Why this matters]
```

**Insight format rules:**
- Lead with the insight (don't bury it)
- Support with data or examples
- Connect to bigger picture
- Use analogies when helpful

### Implication tweet (N-1)

Connect insights to meaning:

```
(N-1) So what does this mean for crypto?

[Key takeaway]

[Implication for reader]

[Optional: prediction or recommendation]
```

## Transition Phrases

- "Here's why:"
- "But here's the thing:"
- "This is where it gets interesting:"
- "Let me explain:"
- "The data shows:"
- "Here's what most people miss:"
- "The real reason is:"

## Examples

### ✅ Good Breakdown Thread

**Example: X Algorithm Breakdown (Indonesian, adapted for CT)**

```
(1/n) Elon just open-sourced X's algorithm.

Now we know EXACTLY how FYP works.

Game changer for crypto creators.

Here's the breakdown 🧵👇

---

(2/n) First, context:

X algorithm is now on GitHub.

We can see the EXACT formula that determines which tweets go viral.

This matters for crypto marketing.

---

(3/n) Factor #1: Engagement Rate

Not total likes, but RATIO.

Likes / Impressions = engagement rate

100 likes from 1000 views (10%) > 1000 likes from 100k views (1%)

---

(4/n) Factor #2: Reply Quality

Not just number of replies.

But LENGTH of replies.

1-word reply = low score
1-paragraph reply = high score

This is why "engagement bait" doesn't work.

---

(5/n) Factor #3: Retweet Speed

How fast your tweet gets RT'd in first hour.

Fast RT = strong signal
Slow RT = weak signal

Golden hour is crucial.

---

(6/n) Factor #4: Negative Signals

What LOWERS your score:

- Block
- Mute
- "Not interested"
- Quick scroll (< 2 sec)

This is why clickbait that disappoints = death.

---

(7/n) Factor #5: Author Authority

Your account has a "trust score".

Built from:
- Follower quality (not quantity)
- Historical engagement
- Verified status
- Account age

New accounts = harder to viral.

---

(8/n) Factor #6: Content Type

Video > Image > Text

But there's a catch:

Video must be watched >50% duration
Image must be clicked for full view
Text must be read >3 seconds

Quality over format.

---

(9/n) Factor #7: Timing

Peak hours matter:

- 7-9 AM (commute)
- 12-1 PM (lunch)
- 6-8 PM (after work)

But this is relative to AUDIENCE timezone.

Check your analytics.

---

(10/n) Factor #8: Thread Performance

Threads are judged as a whole.

If tweet 1 is good but tweets 2-10 are bad = overall score drops.

This is why threads need CONSISTENT quality.

---

(11/n) So what does this mean for crypto creators?

To maximize reach:

1. Focus on engagement RATE, not volume
2. Encourage thoughtful replies
3. Post at peak hours
4. Avoid negative signals
5. Build authority over time

---

(12/12) That's the breakdown, ser!

Now you know the exact FYP formula.

Follow @handle for more crypto marketing insights 🧠

Retweet if helpful 🔄
```

**Why good:**
- Clear context (tweet 2)
- One insight per tweet
- Specific data and examples
- Crypto application (marketing)
- CT voice (ser, 🧠)
- Actionable takeaways

## Type-Specific Tips

1. **Lead with insight:** Don't bury the lede
2. **Use data:** Numbers make claims credible
3. **Provide examples:** Abstract → concrete
4. **Connect dots:** Show how insights relate
5. **Address counterarguments:** "But what about X?"
6. **End with implications:** "So what does this mean?"
7. **Be opinionated:** Analysis requires perspective
8. **Crypto relevance:** Frame insights for crypto audience

## Common Mistakes

### ❌ Too much context, no insights
```
(3/N) The history of X dates back to 1995 when...

[5 tweets of background]

(8/N) So that's the history!
```

**Why bad:** No analysis, just facts.

### ❌ Vague claims without support
```
(3/N) This is really important and will change everything.

Everyone should pay attention to this.
```

**Why bad:** No specific insight, no evidence.

### ✅ Clear insight with support
```
(3/N) Here's what most people miss:

Engagement RATE matters more than total engagement.

A tweet with 100 likes from 1000 views (10% rate) outperforms 1000 likes from 100k views (1% rate).

The algorithm rewards ratio, not volume.
```

**Why good:** Specific insight, data-backed, clear implication.

## When to Use Breakdown

**Good fit:**
- Complex crypto topic needs explanation
- Data or research to analyze
- Pattern recognition in crypto
- Educational deep dive

**Bad fit:**
- Step-by-step process (use tutorial)
- Personal story (use story)
- Resource list (use curated)
