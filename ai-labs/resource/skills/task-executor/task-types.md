# Task Type Workflows

## Article Task

**Input:**
- Topic, audience, length, tone
- Context files (concepts, sources)

**Output:**
- Full article in Section 4: Draft
- Markdown with proper headings
- Internal links to concepts

**Checklist:**
- [ ] Read context
- [ ] Research additional sources
- [ ] Write outline
- [ ] Write full draft
- [ ] Add internal links
- [ ] Proofread

**Estimated time:** 30-60 minutes

---

## Tweet/Thread Task

**Input:**
- Topic, key message, length
- Context files

**Output:**
- Tweet text or numbered thread
- Character count per tweet
- Hashtags/mentions if specified

**Checklist:**
- [ ] Read context
- [ ] Draft hook (first tweet)
- [ ] Draft body (if thread)
- [ ] Draft CTA (last tweet)
- [ ] Check character limits
- [ ] Proofread

**Estimated time:** 5-30 minutes

---

## Research Task

**Input:**
- Research question
- Scope (workspace, KB, web)

**Output:**
- Research report in Section 4
- Sources cited
- Key findings summarized

**Checklist:**
- [ ] Clarify question
- [ ] Search relevant sources
- [ ] Read and synthesize
- [ ] Write findings
- [ ] Cite sources

**Estimated time:** 30 minutes - 2 hours

---

## Code Task

**Input:**
- Feature description
- Language/framework
- Context files (existing code)

**Output:**
- Code in Section 4
- Comments explaining logic
- Test cases if applicable

**Checklist:**
- [ ] Read existing code
- [ ] Design approach
- [ ] Write code
- [ ] Add comments
- [ ] Write tests
- [ ] Verify it runs

**Estimated time:** 30 minutes - 2 hours
