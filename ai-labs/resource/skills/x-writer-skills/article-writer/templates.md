# Templates — X Article Writer

Article structure templates for each style. Copy and adapt based on topic.

---

## Universal Frontmatter

All X articles use this base:

```yaml
---
type: article
platform: x
style: gideon | stacy | jeff | warhol
topic: <main-topic-slug>
status: draft
created: YYYY-MM-DD
---
```

---

## Template 1: Gideon Style (Empathetic Teacher)

**Best for:** Pain points, FOMO antidotes, "how to get unstuck"

```markdown
---
type: article
platform: x
style: gideon
topic: <topic-slug>
status: draft
created: YYYY-MM-DD
---

# [Declarative claim about the problem or solution]

[Hook: Relatable pain point or frustration the reader is experiencing right now]

[Personal angle: "I was there too" + brief story of the mistake]

## [Why this matters / Stakes section]

[1-2 paragraphs explaining what reader loses if they don't address this]

[Reference to community signals: Reddit comments, Twitter sentiment, what others are saying]

## [Framework: 2-3 simple rules]

So to avoid getting [trapped in this problem], I made [N] key rules:

- [Rule 1]
- [Rule 2]
- [Rule 3]

Here's the [exact setup / framework] I'm using:

## [Rule 1 explained]

[2-3 paragraphs breaking down the first rule]

[Personal example or real-world application]

[Why this matters specifically]

## [Rule 2 explained]

[Same pattern as Rule 1]

## [Rule 3 explained]

[Same pattern]

## [My exact setup / Concrete example]

[Show the actual implementation]

- [Component 1]
- [Component 2]
- [Component 3]

[Honest reflection: What's working, what's not perfect]

## [Closing reframe + soft CTA]

[Restate the core insight in new words]

[Validate reader's choice to take action]

[Soft CTA: free resource, newsletter, or "try this approach"]
```

### Filled Example Snippets

**Title options:**
- "If you want to get good at AI, don't fall into the AI Tool Trap"
- "The top 1% of AI users show no loyalty to model providers"
- "AI doesn't have to be a second full-time job"

**Opening template:**
```
"[Verb] [outcome you don't want].

I'm lucky that I [didn't fall into this]. But with [recent change], many [people in similar situation] are [stuck/trapped].

[Brief stakes statement]."
```

```markdown
type: article

status: draft
created: YYYY-MM-DD

[Thesis: 1-2 sentences with the contrarian claim]

- [Bullet point 3: Key finding]
- [Bullet point 4: Key finding]
- [Bullet point 5: What's overlooked]

[Define the category for newcomers]

[Explain the dominant model in 2026]

[List variations: 2-3 main types]

## Who's actually in this market right now

[Player 1] — [Position/metric]
[1-2 sentences description]

[Player 2] — [Position/metric]
[1-2 sentences description]

[Player 3] — [Position/metric]
[1-2 sentences description]

| Aspect | Player 1 | Player 2 | Player 3 |
|---|---|---|---|
| [Metric 1] | Value | Value | Value |
| [Metric 2] | Value | Value | Value |
| [Metric 3] | Value | Value | Value |

## [Dimension 1: Most overlooked design choice]

[2-3 paragraphs explaining this dimension]

[How each player handles it differently]

[Why this matters at scale]

## [Dimension 2: Trust/verification axis]

[Same pattern]

## [Dimension 3: Pricing/economics]

[Same pattern]

[Same pattern]

## What this category actually looks like in [N] years

## Conclusion: What to watch
```

**Title options:**
- "The tokenized stocks race is being won on the wrong scoreboard"


## Style Selection Guide

When unsure which template to use, ask:

| Question | Answer = Style |
|---|---|
| "What's the primary emotion?" | Frustration → Gideon, Curiosity → Stacy, Excitement → Jeff, Skepticism → Warhol |
| "Who's the audience?" | Beginners → Gideon, Analysts → Stacy, Builders → Jeff, Investors → Warhol |
| "What's the goal?" | Help → Gideon, Inform → Stacy, Share → Jeff, Warn → Warhol |
| "What's the main evidence type?" | Anecdotes → Gideon, Data → Stacy, Configs → Jeff, ROI tables → Warhol |
| "Who's the speaker?" | Fellow learner → Gideon, Researcher → Stacy, Builder → Jeff, Critic → Warhol |

## Cross-Style Notes

**Length flexibility:**
- All 4 styles work at 800-2500 words
- Topic complexity drives length, not style

**Tone calibration:**
- Gideon: Most personal, warmest
- Stacy: Most professional, coolest
- Jeff: Most casual, balanced
- Warhol: Most direct, edgiest

**Universal don'ts (any style):**
- ❌ Hype words: "revolutionary", "game-changing"
- ❌ Investment advice: "should buy", "guaranteed returns"
- ❌ Markdown images (Julius adds separately)
- ❌ Emoji in headers
- ❌ Exclamation marks (except in direct quotes)
