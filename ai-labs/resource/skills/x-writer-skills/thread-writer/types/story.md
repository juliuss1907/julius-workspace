# Type Guide — Story (Narrative)

**Purpose:** Tell a compelling narrative with arc  
**Best for:** Case studies, drama, personal journeys, cautionary tales  
**Length:** 8-12 tweets  
**CT Voice:** Moderate slang (Tier 1+2), selective emoji

---

## Narrative Arc

```
Hook: Introduce character + dramatic outcome + crypto context
  ↓
Setup: Initial situation
  ↓
Rising action: Events unfold
  ↓
Conflict/Crisis: Problem emerges
  ↓
Climax: Peak moment
  ↓
Resolution: How it ended
  ↓
Lesson: What crypto can learn
  ↓
CTA: Follow for more stories
```

---

## Hook Patterns

### Pattern A: Character + outcome
```
(1/n) This is [person/project in crypto].

[Dramatic outcome or stat]

Here's what happened:

Thread 🧵👇
```

### Pattern B: Dramatic opening
```
(1/n) [Shocking event or stat in crypto]

[Brief context]

This is the story of [subject]:

Thread 🧵👇
```

### Pattern C: Lesson-first
```
(1/n) [Key lesson about crypto]

I learned this from [person/situation].

Here's the full story:

Thread 🧵👇
```

## CT Voice Calibration

### Slang Usage (Story)

**Frequency:** 2-3 slang terms per thread

**Tier preference:**
- **Tier 1 (frequent):** ser, fren, based, wagmi, ngmi
- **Tier 2 (common):** aped in, rugged, rekt, jeet, cope
- **Tier 3 (rare):** Only if character uses it

**Placement:**
- Hook: "ser, this is wild"
- Body: "they aped in", "got rugged", "pure cope"
- Closing: "wagmi if we learn from this"

**Story-specific patterns:**

**Narrative slang:**
```
✅ "they aped in with $100k"
✅ "got rugged within 24 hours"
✅ "the team was pure cope"
```

**Character voice:**
```
✅ "He said: 'ser, this is the one'"
✅ "They thought: 'wagmi'"
```

### Emoji Usage (Story)

**Frequency:** 3-5 emojis total

**Story-appropriate emojis:**
- 🧵👇 (hook — mandatory)
- 💀 (rekt/failure)
- 🎯 (key moment)
- 🫡 (respect/lesson)

**Avoid:**
- 🚀, 🔥 (unless part of story hype)
- Multiple emojis per tweet
- Emoji that breaks narrative flow

**Placement:**
- Hook: 🧵👇
- Climax: 💀 or 🎯 (if appropriate)
- Closing: 🫡

### Tone (Story)

**Formality:** Casual and narrative
```
✅ "At first, everything looked perfect"
✅ "Then things started to unravel"
❌ "Subsequently, the situation deteriorated" (too formal)
```

**Emotion:** Varies by story arc
```
✅ Setup: Neutral or optimistic
✅ Conflict: Tense
✅ Resolution: Reflective
```

**Stance:** Observational with lesson
```
✅ "Here's what went wrong"
✅ "The lesson? [insight]"
❌ "They were idiots" (too harsh)
```

## Body Structure

### Setup tweets (2-3/N)

Establish initial situation:

```
(2/N) [Character background]

[Initial situation in crypto]

[What they were trying to achieve]
```

### Rising action tweets (4-6/N)

Events unfold:

```
(X/N) [What happened next]

[Key decision or event]

[Consequences or reactions]
```

**Pacing rules:**
- One event per tweet
- Build tension gradually
- Use cliffhangers between tweets
- Include specific details (dates, numbers, quotes)

### Climax tweet (N-3 or N-2)

Peak moment:

```
(X/N) Then [dramatic event].

[Specific details]

[Immediate impact]
```

### Resolution tweets (N-2 to N-1)

How it ended:

```
(X/N) The result?

[Final outcome]

[Current status]
```

---

## Transition Phrases

Use these to maintain narrative flow:

- "At first,"
- "Then,"
- "But here's where it gets crazy:"
- "What happened next?"
- "The turning point came when:"
- "Fast forward to:"
- "By the end,"

## Examples

### ✅ Good Story Thread

**Example: Crypto Scam Story (adapted for CT)**

```
(1/n) This is the Nelk Boys.

They made $23M from their crypto project.

Then scammed 10,000 people.

Here's what happened 🧵👇

---

(2/n) The Nelk Boys are YouTubers with 7.5M subscribers.

Known for pranks and party content.

In 2022, they decided to launch a crypto token.

---

(3/n) March 2022: They announced $FULLSEND token.

Promised:
- Exclusive merch access
- VIP event tickets
- "Community governance"

Fans were hyped.

---

(4/n) Launch day: Token went live.

Price pumped 400% in first hour.

Nelk Boys posted celebration videos.

Everything looked legit.

---

(5/n) But here's where it gets crazy:

Within 24 hours, the team wallet sold $4.5M worth of tokens.

Price crashed 95%.

Fans got rugged.

---

(6/n) The Nelk Boys claimed it was a "mistake."

Said their "developer" sold without permission.

Promised to "make it right."

Never did.

---

(7/n) What actually happened?

Classic pump and dump:

1. Build hype
2. Launch token
3. Fans buy in
4. Team dumps
5. Disappear

Textbook rug pull.

---

(8/n) The aftermath:

- No refunds issued
- Token still exists (worthless)
- Nelk Boys never addressed it again
- Fans lost millions 💀

---

(9/n) The lesson for crypto?

Celebrity projects are almost always exit liquidity.

If they're not building real utility, they're building an exit.

---

(10/10) Don't trust influencers with your money, ser.

Follow @handle for more crypto cautionary tales 🫡

Share to warn others 🔄
```

**Why good:**
- Clear character introduction
- Chronological progression
- Specific numbers and dates
- Dramatic tension
- Clear lesson for crypto
- CT voice (rugged, ser, 🫡)
- Warning CTA

## Type-Specific Tips

1. **Use specific details:** Dates, numbers, quotes make it real
2. **Build tension:** Don't reveal outcome too early
3. **Show, don't tell:** "He sold $4.5M" > "He was greedy"
4. **Include dialogue:** Direct quotes add authenticity
5. **Pace carefully:** One event per tweet, don't rush
6. **End with lesson:** Stories need crypto takeaway
7. **Be vulnerable:** Personal stories require honesty
8. **Crypto context:** Frame story for crypto audience

## Common Mistakes

### ❌ Too much summary, no story
```
(1/N) This person did X and it failed.

Here's why:
- Reason 1
- Reason 2
- Reason 3

The end.
```

**Why bad:** No narrative arc, just bullet points.

### ❌ Burying the hook
```
(1/N) Let me tell you about something interesting.

(2/N) So there was this person.

(3/N) They did some stuff.

(4/N) And then [dramatic outcome].
```

**Why bad:** Hook comes too late, readers already scrolled away.

### ✅ Strong narrative
```
(1/N) This person lost $4.5M in 24 hours.

Here's what happened:

(2/N) At first, everything looked perfect...

[Story unfolds with tension]

(10/N) The lesson? [Clear crypto takeaway]
```

**Why good:** Hook grabs immediately, story builds tension, ends with lesson.

---

## When to Use Story

**Good fit:**
- Real crypto events with clear arc
- Personal experiences with lessons
- Case studies with drama
- Cautionary tales

**Bad fit:**
- Abstract concepts (use breakdown)
- Step-by-step guides (use tutorial)
- Resource lists (use curated)
