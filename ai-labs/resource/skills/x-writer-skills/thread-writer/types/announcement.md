# Type Guide — Announcement (Product Launch)

**Purpose:** Announce product, feature, or major update  
**Best for:** Launches, releases, major milestones  
**Length:** 5-8 tweets  
**CT Voice:** Light slang (Tier 1), moderate emoji

---

## Narrative Arc

```
Hook: What's launching + key benefit + crypto relevance
  ↓
Problem: What this solves in crypto
  ↓
Solution: How it works
  ↓
Features: Key capabilities (2-4)
  ↓
Demo/Visual: Show it in action
  ↓
Availability: How to get it
  ↓
CTA: Try it + share
```

---

## Hook Patterns

### Pattern A: Direct announcement
```
(1/n) Announcing [product/feature for crypto].

[One-line description]

[Key benefit]

Thread 🧵👇
```

### Pattern B: Problem-first
```
(1/n) [Problem statement in crypto]

Today we're launching [solution].

[Key benefit]

Thread 🧵👇
```

### Pattern C: Teaser reveal
```
(1/n) We've been building something for crypto.

Today it's ready.

Introducing [product]:

Thread 🧵👇
```

## CT Voice Calibration

### Slang Usage (Announcement)

**Frequency:** 1-2 slang terms per thread

**Tier preference:**
- **Tier 1 (primary):** gm, ser, based, LFG
- **Tier 2 (rare):** Only if launch-appropriate
- **Tier 3 (avoid):** Too casual for announcement

**Placement:**
- Hook: "gm, we're launching X"
- Features: "this is based"
- Closing: "LFG"

**Announcement-specific patterns:**

**Launch slang:**
```
✅ "gm, we're launching X"
✅ "this is based, here's why"
✅ "LFG, let's build"
```

**Avoid over-hype:**
```
❌ "wagmi to the moon ser" (too much)
❌ "aped in on our own product" (weird)
❌ "ngmi if you miss this" (aggressive)
```

### Emoji Usage (Announcement)

**Frequency:** 4-6 emojis total

**Announcement-appropriate emojis:**
- 🧵👇 (hook — mandatory)
- 🚀 (launch — if appropriate)
- 🎯 (key feature)
- 🫡 (closing)

**Avoid:**
- 💀 (negative)
- Too many hype emojis (🔥🚀⚡ all together)

**Placement:**
- Hook: 🧵👇 (+ 🚀 if major launch)
- Features: 0-1 per tweet
- Closing: 🫡

### Tone (Announcement)

**Formality:** Professional but accessible
```
✅ "We're launching X"
✅ "Available now"
❌ "We are pleased to announce" (too corporate)
```

**Emotion:** Excited but grounded
```
✅ "We're excited to share X"
✅ "This solves Y"
❌ "THIS CHANGES EVERYTHING!!!" (over-hype)
```

**Stance:** Confident but humble
```
✅ "We built X to solve Y"
✅ "Early version, we'll iterate"
❌ "The best product ever" (arrogant)
```

## Body Structure

### Problem tweet (2/N)

Establish the pain point in crypto:

```
(2/N) The problem in crypto:

[Current pain point]

[Why existing solutions fall short]

[Stakes or cost of not solving]
```

### Solution tweet (3/N)

Introduce the solution:

```
(3/N) [Product] solves this by:

[Core mechanism or approach]

[How it's different for crypto]
```

### Feature tweets (4-6/N)

One feature per tweet:

```
(X/N) Feature [number]: [Feature name]

[What it does]

[Benefit to crypto user]

[Optional: visual or example]
```

**Feature format rules:**
- Lead with feature name
- Explain what it does (not just name)
- State user benefit clearly for crypto
- Keep technical jargon minimal

### Demo/Visual tweet (N-2)

Show it in action:

```
(N-2) See it in action:

[Screenshot or demo description]

[What user is seeing]

[Result or outcome]
```

### Availability tweet (N-1)

How to get it:

```
(N-1) Available now:

[Where to access]

[Pricing if applicable]

[Any limitations or requirements]
```

## Type-Specific Tips

1. **Lead with benefit:** Not just "we built X" but "X solves Y for crypto"
2. **Show, don't just tell:** Include visuals or demos
3. **Be specific:** "Track Ethereum wallets" > "Track crypto"
4. **Address objections:** Price, availability, requirements
5. **Make it actionable:** Clear link or next step
6. **Build excitement:** But don't overhype
7. **Keep it short:** 5-8 tweets, announcements should be punchy
8. **Crypto context:** Frame every feature for crypto users

## Common Mistakes

### ❌ Feature dump without benefits
```
(3/N) Features:

- API integration
- Cloud sync
- Multi-platform
- Advanced settings
- Custom themes
```

**Why bad:** Lists features without explaining crypto value.

### ❌ Too much hype, no substance
```
(1/N) 🚀 REVOLUTIONARY NEW PRODUCT 🚀

This will CHANGE CRYPTO FOREVER!!!

Get ready for the FUTURE!!!

🔥🔥🔥
```

**Why bad:** Hype without information.

### ✅ Clear value proposition
```
(1/N) Announcing [Product for crypto].

[One-line what it does]

[One-line who it's for]

Thread 🧵👇

---

(2/N) The problem in crypto: [specific pain point]

(3/N) [Product] solves this by: [specific mechanism]

(4/N) Feature 1: [name] - [crypto benefit]

[... etc]
```

**Why good:** Clear, specific, benefit-focused for crypto.

---

## When to Use Announcement

**Good fit:**
- Crypto product launches
- Major feature releases
- Significant updates
- Milestone announcements

**Bad fit:**
- Minor updates (use single post)
- Explanations (use breakdown)
- Tutorials (use tutorial type)
