# Type Guide — Curated (List/Compilation)

**Purpose:** Share curated list of resources, tools, or insights  
**Best for:** Top N lists, resource compilations, recommendations  
**Length:** 6-12 tweets  
**CT Voice:** Light slang (Tier 1), minimal emoji

---

## Narrative Arc

```
Hook: N items + value proposition + crypto relevance
  ↓
Context: Why these matter to crypto
  ↓
Item 1: First resource + description
  ↓
Item 2: Second resource + description
  ↓
Item 3-N: Remaining items
  ↓
Bonus: Extra tip or resource
  ↓
CTA: Follow for more curated lists
```

---

## Hook Patterns

### Pattern A: Number + category
```
(1/n) [N] [crypto category] [qualifier]

I [spent X hours / curated / tested] to [save you time / find alpha]

Save this thread 🧵👇
```

### Pattern B: Problem-solution
```
(1/n) Struggling with [crypto problem]?

Here are [N] [resources] that [solve it]

[Credibility statement]

Thread 🧵👇
```

### Pattern C: Credibility-first
```
(1/n) I've [used / tested / researched] [N] [crypto category].

Here are the [N] best:

Save this thread 🧵👇
```

## CT Voice Calibration

### Slang Usage (Curated)

**Frequency:** 1-2 slang terms per thread

**Tier preference:**
- **Tier 1 (primary):** ser, fren, alpha, based
- **Tier 2 (rare):** Only if item-specific
- **Tier 3 (avoid):** Too casual for resource list

**Placement:**
- Hook: "alpha thread on X tools"
- Bonus: "this is based"
- Closing: "ser, bookmark this"

**Curated-specific patterns:**

**Value slang:**
```
✅ "alpha thread on crypto tools"
✅ "this list is based"
✅ "ser, save this for later"
```

**Avoid casual slang:**
```
❌ "wagmi frens" (not relevant to list)
❌ "LFG" (too hype)
❌ "aped in" (not about resources)
```

### Emoji Usage (Curated)

**Frequency:** 3-4 emojis total

**Curated-appropriate emojis:**
- 🧵👇 (hook — mandatory)
- 📝 (list/notes)
- 🔖 (bookmark CTA)
- 🫡 (closing)

**Avoid:**
- 🚀, 🔥 (too hype)
- 💀 (negative)
- Emoji per item (cluttered)

**Placement:**
- Hook: 🧵👇
- Body: None (keep clean)
- Closing: 🔖 or 🫡

### Tone (Curated)

**Formality:** Casual but organized
```
✅ "Here are the best tools for X"
✅ "I tested all of these"
❌ "Herein lies a compilation" (too formal)
```

**Emotion:** Helpful and practical
```
✅ "This will save you hours"
✅ "I use these daily"
❌ "These are AMAZING!!!" (too hype)
```

**Stance:** Credible and selective
```
✅ "I tested 50, these are the top 10"
✅ "Here's why I chose these"
❌ "These are the best ever" (no criteria)
```

## Body Structure

### Context tweet (2/N)

Explain selection criteria:

```
(2/N) How I chose these:

- [Criterion 1]
- [Criterion 2]
- [Criterion 3]

[Optional: what I excluded and why]
```

### Item tweets (3/N to N-1)

One item per tweet (or 2 items if short):

```
(X/N) [Number]. [Item name]

[What it does for crypto]

[Why it's valuable]

[Link or how to access]
```

**Item format rules:**
- Lead with item name (bold or clear)
- One-line description
- Specific benefit or use case for crypto
- Include link when applicable

### Bonus tweet (N-1)

Extra value:

```
(N-1) Bonus:

[Extra resource or tip not in main list]

[Why it's worth mentioning for crypto]
```

## Type-Specific Tips

1. **Be specific with numbers:** "10 tools" > "Some tools"
2. **Explain selection criteria:** Why these and not others?
3. **Consistent format:** Each item follows same structure
4. **Include links:** Make it actionable
5. **Add context:** Don't just list, explain value for crypto
6. **Bonus item:** Extra value at the end
7. **Save CTA:** Curated lists are bookmark-worthy
8. **Crypto relevance:** Frame each item for crypto use case

## Common Mistakes

### ❌ No context or criteria
```
(1/N) Here are some tools I like:

1. Tool A
2. Tool B
3. Tool C

The end.
```

**Why bad:** No selection criteria, no value explanation.

### ❌ Inconsistent format
```
(3/N) Tool A - really good for X

(4/N) Tool B is amazing, you should try it, it does Y and Z and also has feature W

(5/N) Tool C: link.com
```

**Why bad:** Different format per item, hard to scan.

### ✅ Consistent, valuable format
```
(3/N) 1. Tool A

Best for: [specific crypto use case]

Why it's valuable: [benefit]

Link: [url]

---

(4/N) 2. Tool B

Best for: [specific crypto use case]

Why it's valuable: [benefit]

Link: [url]
```

**Why good:** Scannable, consistent, actionable, crypto-focused.

---

## When to Use Curated

**Good fit:**
- Resource compilations (tools, articles, people)
- Top N lists (best X for crypto Y)
- Weekly/monthly roundups
- Recommendations with criteria

**Bad fit:**
- Single resource (use post or short thread)
- Step-by-step process (use tutorial)
- Analysis or explanation (use breakdown)
