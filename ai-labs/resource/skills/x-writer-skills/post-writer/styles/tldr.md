# Type Guide — TL;DR (Summary)

**Purpose:** Condense long content into scannable bullet points  
**Best for:** Article summaries, product features, key takeaways

---

## Structure Pattern

```
[Hook: "X in Y bullets" or "TL;DR:"]

[Bullet list or numbered points: 2-5 items]

[Optional: Hashtags or project tag]
```

---

## Hook Patterns

### Pattern A: "X in Y bullets"
```
"Luxx in 3 bullets"
"Crypto cards in 5 points"
"$PROJECT in 4 lines"
```

### Pattern B: "TL;DR:"
```
"TL;DR:"
"Quick summary:"
"The essentials:"
```

### Pattern C: Direct statement
```
"Here's what actually happened:"
"Key features:"
"What you need to know:"
```

---

## Body Format

### Option 1: Numbered list (1-5 items)
```
TL;DR:
1) [Point 1]
2) [Point 2]
3) [Point 3]
```

**When to use:** Sequential info, prioritized order

### Option 2: Bullet list with dashes
```
Crypto cards will be won by deployers, not marketers

TLDR:
- Self-custody spend across 150+ countries
- Real $USDT cashback, not points
- Card econ that read like real #fintech
```

**When to use:** Parallel points, feature lists

### Option 3: Inline bullets
```
$PROJECT in 3 bullets:
Fixed supply ✓ Big allocation ✓ Transparent tokenomics ✓
```

**When to use:** Very short points, space-constrained

---

## Emoji Usage

**Placement:**
- After hook (emphasis): "TL;DR: 👇"
- In bullet points (visual markers): "✓", "→", "•"
- End of tweet (CTA): "🚀", "💎"

**Avoid:**
- Emoji replacing words in bullets
- Different emoji per bullet (inconsistent)

---

## CTA Patterns

TL;DR tweets often skip explicit CTA, but can add:

**Pattern A: Hashtag cluster**
```
#ProjectName #Niche #Blockchain
```

**Pattern B: Project tag**
```
@ProjectHandle
```

**Pattern C: Soft engagement**
```
"Thoughts?"
"What did I miss?"
```

---

## Character Optimization

TL;DR tweets tend to run long. Optimize by:

1. **Shorten bullet text:** Remove articles ("the", "a")
2. **Use symbols:** "→" instead of "leads to"
3. **Abbreviate:** "w/" instead of "with"
4. **Remove redundancy:** If hook says "features", don't repeat in bullets

## Examples

### ✅ Good TL;DR

**Example 1: Numbered list**
```
Luxx in 3 bullets

TL;DR:
1) Fixed supply $LUX on Solana
2) Big allocation for Hero Rewards competition
3) Transparent, structured tokenomics designed for long-term MemeFi gameplay.

#LuxxUp #MemeFi $LUX #Solana #Tokenomics
```
**Char count:** 232 / 280  
**Why good:** Clear structure, specific details, hashtag cluster

**Example 2: Dash list**
```
Crypto cards will be won by deployers, not marketers

TLDR:
- Self-custody spend across 150+ countries
- Real $USDT cashback, not points
- Card econ that read like real #fintech: 4.5% Signature, up to 6% staked metal
- Perps in-app with fast CLOB execution
```
**Char count:** 268 / 280  
**Why good:** Specific metrics, technical details, no fluff

### ❌ Bad TL;DR

**Example: Too vague**
```
Project X is amazing!

TL;DR:
- Great features
- Awesome team
- Huge potential
- Don't miss out!
```
**Why bad:** No specific info, hype words, no value

---

## Type-Specific Tips

1. **Be specific:** "Fixed supply" > "Good tokenomics"
2. **Use numbers:** "150+ countries" > "many countries"
3. **Front-load value:** Most important point first
4. **Skip filler:** No "I think", "In my opinion"
5. **Parallel structure:** All bullets same format (noun phrases or sentences)
