# Type Guide — Announcement (Launch/Update)

**Purpose:** Share news, launch, milestone, or major update  
**Best for:** Product launches, listings, partnerships, events

---

## Structure Pattern

```
[Hook: High-energy statement of what happened]

[Details: What, when, why it matters]

[Hype/CTA: Excitement + action]

[Hashtags/tags]
```

---

## Hook Patterns

### Pattern A: ALL CAPS energy
```
"🚀 BITMART JUST UNLEASHED THE ALTSZN APOCALYPSE! 🔥"
"🔥 MAJOR ANNOUNCEMENT 🔥"
```

### Pattern B: Direct statement
```
"Probably my last update on @Project for a while"
"New week new opportunities"
```

### Pattern C: Teaser format
```
"I discovered some interesting things about @Project today."
"Something big is coming..."
```

---

## Body Development

### High-energy announcements:

**Pattern:**
```
[CAPS HOOK]

[What launched/happened]

[Why it matters - hype language]

[CTA]

[Hashtags]
```

**Example:**
```
🚀 BITMART JUST UNLEASHED THE ALTSZN APOCALYPSE! 🔥

The one true altseason token is now live, community forged, Solana born, and ready to devour the charts.

$ALTSZN season starts NOW. LFG legends! 💎

#ALTSZN
```

### Professional announcements:

**Pattern:**
```
[Calm hook]

[Details with specifics]

[Reasoning/context]

[Optional soft CTA]
```

**Example:**
```
Probably my last update on @Collector_Crypt for a while

tldr: $CARDS will remain my biggest crypto holding this year and will continue to add on dips

- Very bullish on the team
- When regulation allows it the token will 'officially' get utility
- The inventory is worth $30M atm
- Systemic buybacks will come

Don't really care about short term price action.
```

---

## Emoji Usage

### High-energy style:
- **Heavy emoji use:** 5-8 emojis
- **Placement:** Hook, key points, CTA
- **Types:** 🚀, 🔥, 💎, ⚡, 🌊

### Professional style:
- **Minimal emoji:** 1-3 emojis
- **Placement:** Hook or CTA only
- **Types:** 🫡, ✓, 📊

---

## CTA Patterns

**Pattern A: Hype call**
```
"LFG legends! 💎"
"Let's get it 🚀"
"Season starts NOW"
```

**Pattern B: Information**
```
"More info in my previous tweets"
"Turn on notifications"
"Link in bio"
```

**Pattern C: Soft/none**
```
"GLFH" (Good luck, have fun)
"Thoughts?"
[No explicit CTA]
```

---

## Hashtag Strategy

Announcements benefit from hashtags for reach.

**Rules:**
- 2-4 hashtags max
- Place at end
- Mix: Project + niche + blockchain

**Examples:**
```
#ProjectName #DeFi #Solana
#ALTSZN #MemeFi #Tokenomics
```

## Examples

### ✅ Good Announcement

**Example 1: High-energy launch**
```
🚀 BITMART JUST UNLEASHED THE ALTSZN APOCALYPSE! 🔥

The one true altseason token is now live, community forged, Solana born, and ready to devour the charts.

$ALTSZN season starts NOW. LFG legends! 💎
#ALTSZN
```
**Char count:** 219 / 280  
**Why good:** High energy, clear what launched, hype CTA

**Example 2: Professional update**
```
Probably my last update on @Collector_Crypt for a while

tldr: $CARDS will remain my biggest crypto holding this year and will continue to add on dips

- Very bullish on the team
- When regulation allows it the token will 'officially' get utility (most importantly the token owns the treasury + revenue)
- The inventory is worth $30M atm
- Systemic buybacks will come, but won't be announced untill months after
- Buying back VC allocations

Don't really care about short term price action. Might get some more good entries if the broader crypto market goes down.

More info in my previous tweets, GLFH.
```
**Why good:** Specific details, reasoning, calm confidence

**Example 3: Casual announcement**
```
gm my jpeg frens 🫡

new week new opportunities, lets get it
```
**Char count:** 58 / 280  
**Why good:** Short, friendly, motivational

### ❌ Bad Announcement

**Example: Vague hype**
```
🚀🚀🚀 HUGE NEWS COMING 🚀🚀🚀

This will change EVERYTHING!!!

Get ready! 🔥🔥🔥

#Crypto #Moon #100x
```
**Why bad:** No actual info, emoji spam, generic hype

---

## Type-Specific Tips

1. **Match energy to news:** Big launch = high energy, update = calm
2. **Be specific:** "Now live on Bitmart" > "Big news"
3. **Front-load the news:** Don't bury what happened
4. **Use project tags:** @mentions for visibility
5. **Hashtags for reach:** Announcements benefit from discoverability
