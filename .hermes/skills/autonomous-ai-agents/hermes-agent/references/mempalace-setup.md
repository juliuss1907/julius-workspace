# MemPalace — Hermes Memory Expansion

> How to give Hermes persistent, searchable, long-term memory using MemPalace.
> Set up 2026-05-22 for Julius's workspace. 100% local, no API key required.

## Why MemPalace

Hermes has a built-in memory system limited to ~2,200 chars. MemPalace provides:
- **Unlimited capacity** — stored as local markdown files
- **Semantic + keyword search** — ChromaDB backend with ONNX embeddings (all-MiniLM-L6-v2)
- **MCP server** — 29 tools auto-registered as `mcp_mempalace_*` in Hermes
- **Wake-up context** — ~350-token summary for new sessions via `mempalace wake-up`
- **AAAK compression** — ~30x reduction for long-term storage

## Installation

```bash
# Install into Hermes venv (NOT system pip)
uv pip install mempalace --python ~/.hermes/hermes-agent/venv/bin/python

# Verify
~/.hermes/hermes-agent/venv/bin/mempalace --version
# → mempalace v3.3.5
```

## Directory Structure

```
~/.hermes/mempalace/
├── mempalace.yaml              # Generated by `mempalace init`
├── mcp-wrapper.sh              # Wrapper for MCP server (ensures correct cwd)
├── auto-mine.sh                # Cron script for weekly re-index
└── wings/hermes-memory/rooms/  # Your memory files live here
    ├── system/                 # Rules, conventions, setup docs
    ├── x/                      # CT voice, xurl setup
    └── coin68/                 # Pipeline plan, article research
```

## Setup Steps

### 1. Create directory and files

```bash
mkdir -p ~/.hermes/mempalace/wings/hermes-memory/rooms/{system,x,coin68}
# Add .md files with your memory entries into each room/
```

### 2. Initialize the palace

```bash
cd ~/.hermes/mempalace
mempalace init . --yes --no-llm
```

Use `--no-llm` to skip LLM-assisted entity detection (faster, fully local).

### 3. Mine files into palace

```bash
mempalace mine wings/ --wing hermes-memory --agent Markus --limit 100
```

### 4. Test search

```bash
mempalace search "CT voice rules"
mempalace search "Coin68 pipeline"
```

### 5. Test wake-up context

```bash
mempalace wake-up
# → ~350 tokens summary of all memory entries
```

## MCP Server Integration

### Wrapper script (`mcp-wrapper.sh`)

```bash
#!/bin/bash
cd /home/julius/.hermes/mempalace
exec mempalace mcp
```

Make executable: `chmod +x mcp-wrapper.sh`

### Config (`~/.hermes/config.yaml`)

```yaml
mcp_servers:
  mempalace:
    command: "/home/julius/.hermes/mempalace/mcp-wrapper.sh"
    args: []
    timeout: 30
    connect_timeout: 30
```

### After config

Restart Hermes. On startup it auto-connects and registers 29 tools:
- `mcp_mempalace_search` — semantic search
- `mcp_mempalace_wake_up` — session context generator
- `mcp_mempalace_mine` — re-index files
- ... and 26 more

## Cron Auto-Mine

Keeps the index fresh as you add new `.md` files to rooms.

### Script (`auto-mine.sh`)

```bash
#!/bin/bash
cd /home/julius/.hermes/mempalace || exit 1
mempalace mine wings/ --wing hermes-memory --agent Markus --limit 100
mempalace compress
```

### Cron job

```
Schedule: 0 9 * * 0 (Sunday 9 AM)
Mode: no_agent=True (script-only, no LLM needed)
Script: auto-mine.sh (symlinked to ~/.hermes/scripts/)
```

## Adding New Memories

1. Write or edit a `.md` file in the appropriate room:
   ```
   ~/.hermes/mempalace/wings/hermes-memory/rooms/system/new-rule.md
   ```
2. Either:
   - Wait for Sunday auto-mine cron, OR
   - Run manually: `mempalace mine wings/ --wing hermes-memory --agent Markus`

## Key Commands Cheatsheet

| Command | What it does |
|---------|-------------|
| `mempalace search "query"` | Semantic + keyword search |
| `mempalace wake-up` | ~350-token session context |
| `mempalace mine <dir> --wing <name>` | Index new/changed files |
| `mempalace compress` | Apply AAAK compression |
| `mempalace status` | Check palace health |
| `mempalace init . --yes --no-llm` | First-time setup |

## Pitfalls

- **Python version mismatch**: `pip install mempalace` may install to system Python (3.14) while Hermes uses 3.11 venv. Always use `uv pip install mempalace --python <venv>/bin/python`.
- **Mine timeout**: Large directories may exceed 60s terminal timeout. Use `--limit N` or run in background with longer timeout.
- **Rooms not detected**: If `mine` puts everything in `general` room, run `init` first to detect folder structure, then `mine` from the wing directory.
- **MCP auth needed**: `mempalace mcp` runs stdio server. No additional auth required — it's fully local.
- **Cron script must be relative**: Hermes cron requires scripts in `~/.hermes/scripts/`. Symlink your actual script there.
