# Type Guide — Engagement (Question/Discussion)

**Purpose:** Start conversation, gather opinions, create discussion  
**Best for:** Polls, debates, community questions, feedback

---

## Structure Pattern

```
[Setup: Context or data]

[Question or prompt]

[Optional: Your take or additional context]
```

---

## Hook Patterns

### Pattern A: Data-driven setup
```
"Everyone was expecting 'bullish' after the Clarity Act passed 👇

Here's what actually happened:

$BTC dropped -$5,400 in 5 days
$110B wiped from the market
$1.4B in long positions liquidated

Classic 'buy the rumor, sell the news.'

Do you think we've hit the bottom, or is there more to go?"
```

### Pattern B: Teaser + question
```
"I discovered some interesting things about @Polymarket today. I'll share them soon, so turn on notifications brah 👀

Also heard from a source that @wallchain's TGE might still be far away 🤔

What do you guys think?"
```

### Pattern C: Direct question
```
"Which TGE lands first, $POLY or $QUACK?"
```

---

## Question Patterns

### Binary choice:
```
"Do you think we've hit the bottom, or is there more to go?"
"Which one wins: X or Y?"
```

### Open-ended:
```
"What do you guys think?"
"Thoughts?"
"What am I missing?"
```

### Poll-style (without actual poll):
```
"Drop your prediction below 👇"
"Comment your pick"
```

---

## Setup Techniques

### Technique 1: Data contrast
Present unexpected data, then ask for interpretation.

```
"Everyone expected X.

Here's what happened:
- [Data point 1]
- [Data point 2]
- [Data point 3]

[Question]"
```

### Technique 2: Rumor/teaser
Share partial info, create curiosity.

```
"I heard from a source that [rumor].

Also [related info].

What do you guys think?"
```

### Technique 3: Personal metric
Share your own data, invite comparison.

```
"I earned 10.02 Quacks yesterday 🦆

Now the real question: [question]"
```

---

## Emoji Usage

**Placement:**
- Setup emphasis: 👇, 👀, 🤔
- Question reinforcement: 🦆, 💭, 🧵
- CTA: 👇 (for replies)

**Avoid:**
- Emoji in data points (looks unprofessional)
- Question mark emoji (redundant with "?")

---

## CTA Patterns

Engagement tweets MUST end with clear invitation:

**Pattern A: Direct question**
```
"What do you guys think?"
"Thoughts?"
```

**Pattern B: Action request**
```
"Drop your prediction below 👇"
"Turn on notifications"
"Comment your pick"
```

**Pattern C: Binary choice**
```
"Which one: A or B?"
"Bottom or more downside?"
```

## Examples

### ✅ Good Engagement

**Example 1: Data-driven**
```
Everyone was expecting "bullish" after the Clarity Act passed 👇

Here's what actually happened:

$BTC dropped -$5,400 in 5 days
$110B wiped from the market
$1.4B in long positions liquidated

Classic "buy the rumor, sell the news."

Do you think we've hit the bottom, or is there more to go?
```
**Char count:** 279 / 280  
**Why good:** Specific data, clear question, binary choice

**Example 2: Teaser format**
```
I discovered some interesting things about @Polymarket today. I'll share them soon, so turn on notifications brah 👀

Also heard from a source that @wallchain's TGE might still be far away 🤔
What do you guys think?

Either way, I'm still quacking and earning daily.
I earned 10.02 Quacks yesterday 🦆

Now the real question: Which TGE lands first, $POLY or $QUACK?
```
**Why good:** Multiple hooks, personal metric, clear question

### ❌ Bad Engagement

**Example: No clear question**
```
Crypto is interesting lately.

A lot of things happening.

Bullish vibes! 🚀
```
**Why bad:** No question, no invitation to respond, vague

---

## Type-Specific Tips

1. **Always end with question:** Engagement requires explicit invitation
2. **Provide context:** Don't ask question in vacuum
3. **Make it easy to answer:** Binary > open-ended for replies
4. **Use data when possible:** Numbers make setup more credible
5. **Tease value:** "I'll share soon" creates anticipation
