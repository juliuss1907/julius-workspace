# Type Guide — Quote Tweet (Reaction)

**Purpose:** React to someone else's tweet with added commentary  
**Best for:** Amplify, critique, add context, or build on original post

---

## Structure Pattern

```
[Your take/reaction]

[Why it matters or additional context]

[Optional: CTA or question]

[Quote the original tweet]
```

---

## Reaction Patterns

### Pattern A: Agreement + amplification
```
"This 💯

[Why you agree + what others miss]

[Original tweet]"
```

### Pattern B: Contrarian take
```
"Hot take on this:

[Your different perspective]

[Original tweet]"
```

### Pattern C: Add context
```
"Important context everyone's missing:

[Additional info or data]

[Original tweet]"
```

### Pattern D: Build on insight
```
"Building on this:

[Your extension of the idea]

[Original tweet]"
```

---

## Commentary Techniques

### Technique 1: Data addition
Original says something qualitative, you add numbers.

```
"The numbers back this up:

- [Stat 1]
- [Stat 2]
- [Stat 3]

[Original tweet]"
```

### Technique 2: Personal experience
Original makes claim, you validate with your story.

```
"Can confirm. I've been [doing X] for [time] and [result].

[Why this matters]

[Original tweet]"
```

### Technique 3: Contrarian angle
Original has consensus view, you challenge it.

```
"Respectfully disagree.

[Your counter-argument]

[Why this matters]

[Original tweet]"
```

### Technique 4: Simplification
Original is complex, you make it accessible.

```
"TL;DR for those who need it:

[Simplified version]

[Original tweet]"
```

---

## Emoji Usage

**Placement:**
- Agreement emphasis: 💯, ✅, 🎯
- Attention: 👀, 🚨, ⚠️
- Thinking: 🤔, 💭
- Support: 🙌, 👏

**Avoid:**
- Emoji that contradict tone (🤣 on serious topic)
- Too many (max 2-3 in quote tweet)

---

## CTA Patterns

Quote tweets often skip explicit CTA, but can add:

**Pattern A: Question to audience**
```
"What do you think?"
"Am I missing something?"
```

**Pattern B: Tag relevant people**
```
"@Person thoughts?"
```

**Pattern C: Invitation**
```
"Let's discuss"
"Thread on this coming soon"
```

---

## Tone Calibration

### When agreeing:
✅ "This is spot on."
✅ "Exactly this."
❌ "OMG SO TRUE!!!" (too enthusiastic)

### When disagreeing:
✅ "Respectfully disagree."
✅ "Different take:"
❌ "This is completely wrong." (too harsh)

### When adding context:
✅ "Important to note:"
✅ "Context everyone's missing:"
❌ "Actually..." (condescending)

---

## Character Management

Quote tweets are tricky because original tweet takes space.

**Optimization strategies:**

1. **Keep your commentary tight:** 100-150 chars max
2. **Use line breaks:** Separate your take from quote
3. **Front-load value:** First line = your main point
4. **Skip filler:** No "I think", "In my opinion"

## Examples

### ✅ Good Quote Tweet

**Example 1: Agreement + data**
```
This 💯

The numbers back it up:
- 31% of Polymarket traders are profitable
- Most lose money chasing narratives
- Edge comes from pricing, not prediction

[Quote: Original tweet about Polymarket difficulty]
```
**Why good:** Adds specific data, validates claim, concise

**Example 2: Personal validation**
```
Can confirm. 

$CARDS will remain my biggest crypto holding this year and will continue to add on dips.

- Very bullish on the team
- Token owns treasury + revenue
- Inventory worth $30M

Don't care about short term price action.

[Quote: Original tweet about $CARDS]
```
**Why good:** Personal stake disclosed, specific reasoning, calm confidence

**Example 3: Contrarian angle**
```
Respectfully disagree.

Crypto's biggest competitor isn't banks.

It's inconvenience.

Too many wallets. Too many bridges. Too many fees.

That's why simplification > innovation right now.

[Quote: Original tweet claiming banks are main competitor]
```
**Why good:** Polite disagreement, clear counter-argument, specific examples

### ❌ Bad Quote Tweet

**Example: No added value**
```
This! 🔥🔥🔥

So true!!! 

Everyone needs to see this! 🚀

[Quote: Original tweet]
```
**Why bad:** No original insight, just cheerleading, emoji spam

---

## Type-Specific Tips

1. **Add value:** Don't just say "This" — explain why
2. **Be concise:** Original tweet takes space, keep commentary tight
3. **Respect original:** Even when disagreeing, stay professional
4. **Front-load insight:** First line = your main point
5. **Use data when possible:** Numbers strengthen your take

---

## When NOT to Quote Tweet

Skip quote tweet if:
- You have nothing to add (just like/retweet)
- Your take is too long (write separate thread)
- Topic is sensitive and you're not adding constructive value
- You're just promoting yourself (looks opportunistic)
