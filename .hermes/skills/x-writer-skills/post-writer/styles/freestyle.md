# Type Guide — Freestyle (Casual)

**Purpose:** Casual thoughts, greetings, vibes, random observations  
**Best for:** GM posts, weekend vibes, personal updates, community building

---

## Structure Pattern

```
[Greeting or casual opener]

[Thought or observation]

[Optional: Motivational close or question]
```

---

## Opening Patterns

### Pattern A: GM/GN greeting
```
"gm my jpeg frens 🫡"
"gm apes"
"gn crypto twitter"
```

### Pattern B: Time-based
```
"Morning, let's talk crypto over breakfast ☕🍳"
"New week new opportunities"
"Weekend vibes"
```

### Pattern C: Casual observation
```
"Just looking at [thing]"
"Been thinking about [topic]"
"Interesting day in [niche]"
```

---

## Body Development

Freestyle tweets are intentionally loose, but follow these patterns:

### Pattern 1: Greeting + vibe
```
"gm my jpeg frens 🫡

new week new opportunities, lets get it"
```

### Pattern 2: Observation + thought
```
"Just looking at the @TermMaxFi range order setter

Seriously changing the game for fixed rate lending

This isn't just borrowing or lending
This is becoming your own sovereign market maker"
```

### Pattern 3: Personal update
```
"Been grinding [activity] all week

[Result or feeling]

[Casual close]"
```

---

## Emoji Usage

Freestyle tweets are most emoji-friendly:

**Common emojis:**
- Greeting: 🫡, ☕, 🍳, 🌅
- Positive: 🚀, 💎, ✨, 🌊
- Casual: 🦆, 🐸, 🦍, 🖼️ (jpeg)
- Thinking: 💭, 🤔

**Placement:**
- After greeting
- End of thought
- Emphasis points

**Freestyle = more emoji OK:** 3-6 emojis acceptable

---

## Tone Markers

### Casual language:
- "frens" not "friends"
- "ser" not "sir"
- "lets get it" not "let's achieve our goals"
- "gm" not "good morning"

### Slang integration:
- "aped in", "rugged", "degen", "wagmi", "ngmi"
- Use naturally, not forced
- 1-2 per tweet max

### Contractions:
- "lets" not "let us"
- "thats" not "that is"
- Casual = less formal grammar OK

---

## CTA Patterns

Freestyle tweets often skip CTA, but can add:

**Pattern A: Motivational**
```
"lets get it"
"LFG"
"wagmi"
```

**Pattern B: Community question**
```
"hows everyone doing?"
"what are you working on?"
"whats your play today?"
```

**Pattern C: None**
```
[Just ends with thought or vibe]
```

---

## Type-Specific Tips

1. **Be authentic:** Freestyle = real you, not performance
2. **Keep it short:** 50-150 chars often enough
3. **Use slang naturally:** If it feels forced, skip it
4. **Community over self:** "gm frens" > "look at my gains"
5. **Emoji = personality:** More OK here than other types

---

## When to Use Freestyle

**Good times:**
- Morning/evening greetings
- Weekend check-ins
- Personal updates
- Casual observations
- Community building

**Avoid for:**
- Important announcements (use announcement type)
- Strong opinions (use hot-take type)
- Detailed info (use tldr type)
