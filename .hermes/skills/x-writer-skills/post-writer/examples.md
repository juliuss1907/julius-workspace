## Common Patterns Across Types

### Opening hooks that work:
- "gm [audience]"
- "Hot take:"
- "[Project] in [N] bullets"
- "Everyone was expecting X 👇"
- "Just looking at..."

### Closing CTAs that work:
- "What do you guys think?"
- "LFG" / "lets get it"
- "Thoughts?"
- "[Hashtag cluster]"
- "@ProjectTag"

### Emoji that work everywhere:
- 👇 (attention down)
- 🔥 (hype/hot)
- 💎 (diamond hands/value)
- 🚀 (bullish/launch)
- 🫡 (respect/salute)

## CT-Specific Examples

Real CT posts demonstrating proper voice, slang, and emoji usage.

### Example 1: Chill Analysis (Skeptical)

```

interesting design but:
- TVL mostly mercenary
- team anon (red flag)
- tokenomics sus

passing for now 👀
```

**Why good:**
- Chill tone (not aggressive)
- Specific observations
- Self-aware (not claiming certainty)
- CT emoji (👀)
- Tier 1 slang natural

## Anti-Pattern Examples (What NOT to Do)

### ❌ Example A: Forced Slang
```
gm ser frens anons, this based alpha is wagmi ngmi degen mode LFG 🚀
```
**Why bad:** Slang spam, unreadable, trying too hard.

---

### ❌ Example B: No Crypto Tie-In
```
5 productivity tips:

1. Wake up early
2. Exercise daily
3. Eat healthy
4. Sleep well
5. Stay focused
```
**Why bad:** Zero crypto connection, wrong audience.

---

### ❌ Example C: Corporate Voice
```
We're excited to announce our strategic partnership to leverage synergies and drive innovation in the blockchain space! 🎉✨
```
**Why bad:** Corporate jargon, not CT voice, wrong emojis.

---

### ❌ Example D: Guru Positioning
```
As someone who's been in crypto since 2013, let me tell you why you're all wrong about X...
```
**Why bad:** Authority positioning, not community-oriented.

---

### ❌ Example E: Unclear Sarcasm
```
This is totally going to work out great.
```
**Why bad:** Sarcasm unclear without context or emoji.

---

### ❌ Example F: Emoji Spam
```
🚀🔥💎⚡🌊 This is huge! 🚨👀🧠📝🎯
```
**Why bad:** Unreadable, looks desperate.

---

### ❌ Example G: Tone-Deaf on Serious Topic
```
lol another hack 😂

classic crypto, never change 🤣

ngmi if you got rekt 💀
```
**Why bad:** People lost money, not funny, insensitive.
