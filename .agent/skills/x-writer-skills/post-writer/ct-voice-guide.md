# CT Voice Guide — Post Writer

**Purpose:** Tone calibration for Crypto Twitter posts  
**Scope:** Single tweets (280 chars)  
**Last updated:** 2026-05-19

---

## CT Voice Spectrum

CT voice sits on 3 axes. Adjust based on topic and intent.

### Axis 1: Formality

```
Casual ←――――――――――――――――――――→ Professional
"ser this is based"        "This represents significant progress"
```

**Default:** Casual (70% of posts)

**When to shift professional:**
- Security vulnerabilities
- Regulatory updates
- Major hacks or exploits
- Legal issues

**Examples:**

**Casual (standard):**
```
"gm frens 🫡

new Uniswap V4 hooks are actually insane

this changes everything for custom AMMs"
```

**Professional (serious topic):**
```
"🚨 Critical vulnerability in X protocol

Funds at risk. Withdraw immediately.

Details: [link]"
```

---

### Axis 2: Emotion

```
Chill ←――――――――――――――――――――→ Hype
"kinda interesting ngl"    "THIS CHANGES EVERYTHING"
```

**Default:** Chill (80% of posts)

**When to shift hype:**
- Major launches (rare)
- Genuine breakthroughs
- Community wins
- Memes and culture

**Examples:**

**Chill (standard):**
```
"been testing X for a week

pretty solid tbh

few rough edges but the core idea is based"
```

**Hype (major launch):**
```
"🚀 WE'RE SO BACK

X just launched and it's everything we hoped for

LFG frens 🔥"
```

**Over-hype (avoid):**
```
❌ "🚀🔥 REVOLUTIONARY BREAKTHROUGH 🔥🚀

THIS WILL 100X YOUR PORTFOLIO!!!

GET IN NOW OR NGMI FOREVER!!!"
```

---

### Axis 3: Stance

```
Skeptical ←――――――――――――――――――――→ Optimistic
"another rug incoming"         "wagmi frens"
```

**Default:** Skeptical-neutral (60% of posts)

**When to shift optimistic:**
- Real progress (not hype)
- Community achievements
- Personal wins

**When to shift more skeptical:**
- New launches (default skeptical)
- Hype narratives
- Unproven claims

**Examples:**

**Skeptical (new launch):**
```
"another 'revolutionary' L2 launching

same promises, different name

show me usage, not TVL"
```

**Neutral (analysis):**
```
"X protocol has interesting design

trade-offs:
- pro: capital efficient
- con: complex UX

time will tell"
```

**Optimistic (real progress):**
```
"X shipped what they promised

no delays, no excuses

this is how you build in crypto 🫡"
```

## Tone Patterns by Post Type

### TL;DR
- **Formality:** Casual
- **Emotion:** Chill
- **Stance:** Neutral

**Pattern:**
```
"X in 3 bullets:

- [point 1]
- [point 2]
- [point 3]

[optional: mild take]"
```

---

### Hot Take
- **Formality:** Casual
- **Emotion:** Chill to moderate
- **Stance:** Skeptical or contrarian

**Pattern:**
```
"hot take:

[contrarian claim]

[brief reasoning]

[optional: community question]"
```

---

### Announcement
- **Formality:** Casual to professional (depends on seriousness)
- **Emotion:** Chill to hype (depends on magnitude)
- **Stance:** Optimistic (but not over-hype)

**Pattern:**
```
"[what launched]

[key benefit]

[availability]

[CTA]"
```

---

### Engagement
- **Formality:** Casual
- **Emotion:** Chill
- **Stance:** Neutral to curious

**Pattern:**
```
"[setup with data or context]

[question to audience]

[optional: your take]"
```

---

### Quote Tweet
- **Formality:** Match original or go casual
- **Emotion:** Chill
- **Stance:** Depends on agreement level

**Pattern:**
```
"[your take - agreement/disagreement/addition]

[brief reasoning]

[optional: question]"
```

---

### Freestyle
- **Formality:** Very casual
- **Emotion:** Chill
- **Stance:** Positive/community

**Pattern:**
```
"gm [audience] 🫡

[casual thought or vibe]

[optional: motivational close]"
```

## Self-Awareness Patterns

CT values self-awareness. Acknowledge limitations and mistakes.

### Admitting Uncertainty

**Good:**
```
✅ "not sure if this is the right take, but..."
✅ "could be wrong, but here's what I'm seeing"
✅ "still figuring this out, but..."
```

**Bad:**
```
❌ "I'm 100% certain that..."
❌ "This will definitely..."
❌ "Trust me, I know..."
```

---

### Acknowledging Mistakes

**Good:**
```
✅ "I was wrong about X. Here's why:"
✅ "got rekt on this trade. lesson learned:"
✅ "called this wrong. updating my thesis:"
```

**Bad:**
```
❌ "I never said that"
❌ "You misunderstood me"
❌ [Deleting wrong takes without acknowledgment]
```

---

### Sharing Losses

**Good:**
```
✅ "aped in at $10, now $2. pain."
✅ "this didn't work out. here's what I learned:"
✅ "got rugged. should've seen the red flags:"
```

**Bad:**
```
❌ "I made 10x on this!" [only shares wins]
❌ "This was obvious" [after the fact]
❌ [Never mentions losses]
```

## Sarcasm and Irony

CT uses sarcasm frequently. Use carefully.

### When Sarcasm Works

**Mocking hype:**
```
✅ "another 'Ethereum killer' launching

surely this one will be different"
```

**Self-deprecating:**
```
✅ "spent 6 hours debugging

turns out I forgot to save the file

gigabrain move"
```

**Calling out patterns:**
```
✅ "step 1: launch token
step 2: promise utility
step 3: [crickets]

tale as old as crypto"
```

### When Sarcasm Doesn't Work

**Serious topics:**
```
❌ "oh great, another hack. classic crypto lol"
[People lost money, not funny]
```

**Punching down:**
```
❌ "imagine not understanding this. ngmi."
[Dismissive, not helpful]
```

**Unclear intent:**
```
❌ "this is totally going to work"
[Is this sarcastic or genuine? Unclear.]
```

## Community-Oriented Language

CT is community-first. Use "we" over "I" when appropriate.

### Good Community Voice

```
✅ "we're all learning together"
✅ "let's figure this out"
✅ "wagmi frens"
✅ "we're so back"
```

### Bad Self-Centered Voice

```
❌ "I figured this out before everyone"
❌ "Follow me to learn the secrets"
❌ "I'm the only one saying this"
❌ "You need to listen to me"
```

## Tone Anti-Patterns

### ❌ Guru Positioning
```
"As someone who's been in crypto since 2015, let me tell you..."
```
**Why bad:** Authority positioning, not CT style.

### ❌ Fake Humility
```
"I'm just a simple degen, but here's my 50-tweet thesis on macroeconomics..."
```
**Why bad:** Performative, not genuine.

### ❌ Aggressive Certainty
```
"If you don't understand this, you're ngmi and shouldn't be in crypto."
```
**Why bad:** Dismissive, not community-oriented.

### ❌ Corporate Speak
```
"We're excited to announce our strategic partnership to leverage synergies..."
```
**Why bad:** Too formal, not CT voice.

---

## Tone Calibration Checklist

Before posting, verify tone:

**Formality:**
- [ ] Casual enough for CT (unless serious topic)
- [ ] No corporate jargon
- [ ] Slang used naturally

**Emotion:**
- [ ] Not over-hyped (unless genuine breakthrough)
- [ ] Not too bland (show some personality)
- [ ] Matches topic magnitude

**Stance:**
- [ ] Default skeptical on new launches
- [ ] Optimistic on real progress
- [ ] Self-aware about limitations

**Community:**
- [ ] "We" over "I" when appropriate
- [ ] Not guru positioning
- [ ] Acknowledges shared experience
