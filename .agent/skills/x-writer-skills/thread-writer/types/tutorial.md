# Type Guide — Tutorial (Step-by-Step)

**Purpose:** Teach reader how to do something specific  
**Best for:** How-to guides, walkthroughs, technical tutorials  
**Length:** 6-12 tweets  
**CT Voice:** Moderate slang (Tier 1), minimal emoji

---

## Narrative Arc

```
Hook: What they'll learn + result + crypto relevance
  ↓
Setup: Prerequisites or context
  ↓
Step 1: First action
  ↓
Step 2: Second action
  ↓
Step 3-N: Remaining steps
  ↓
Result: What they achieved
  ↓
CTA: Follow for more tutorials
```

---

## Hook Patterns

### Pattern A: Result-focused
```
(1/n) Tutorial: How to [do X in crypto]

[Brief description]

By the end, you'll be able to [specific result].

Save this thread 🧵👇
```

### Pattern B: Problem-solution
```
(1/n) Struggling with [crypto problem]?

Here's the exact process I use to [solve it].

[Time/cost saved or result achieved]

Step-by-step tutorial 🧵👇
```

### Pattern C: Credibility-based
```
(1/n) I've [done X in crypto] for [time period].

Here's my exact process for [achieving Y].

[Specific result or metric]

Tutorial thread 🧵👇
```

## CT Voice Calibration

### Slang Usage (Tutorial)

**Frequency:** 2-3 slang terms per thread

**Tier preference:**
- **Tier 1 (primary):** gm, ser, fren, based, alpha
- **Tier 2 (occasional):** aped in, LFG
- **Tier 3 (avoid):** Too technical for tutorial tone

**Placement:**
- Hook: "gm, here's how to X"
- Body: "this step is based" (approval)
- Closing: "LFG, start building"

**Tutorial-specific patterns:**

**Encouraging slang:**
```
✅ "you've got this, fren"
✅ "this is based, keep going"
✅ "LFG, let's build"
```

**Avoid harsh slang:**
```
❌ "ngmi if you skip this" (too harsh)
❌ "skill issue" (dismissive)
❌ "cope" (mocking)
```

### Emoji Usage (Tutorial)

**Frequency:** 3-5 emojis total

**Tutorial-appropriate emojis:**
- 🧵👇 (hook — mandatory)
- 📝 (taking notes)
- 🎯 (key step)
- 🫡 (closing)

**Avoid:**
- 💀 (too negative)
- 🚀 (too hype)
- Multiple emojis per step

**Placement:**
- Hook: 🧵👇
- Body: 0-1 per tweet (key steps only)
- Closing: 🫡

### Tone (Tutorial)

**Formality:** Casual-friendly
```
✅ "Here's how to do X"
✅ "Next, you'll want to Y"
❌ "Execute the following procedure" (too formal)
```

**Emotion:** Encouraging and supportive
```
✅ "This might feel tricky, but you've got this"
✅ "Don't worry if it takes a few tries"
❌ "This is easy" (dismissive)
```

**Stance:** Helpful and patient
```
✅ "Take your time with this step"
✅ "Common mistake: X. Here's how to avoid it"
❌ "Just do it" (not helpful)
```

## Body Structure

### Setup tweet (2/N)

Establish prerequisites or context:

```
(2/N) Before we start, you'll need:

- [Requirement 1]
- [Requirement 2]
- [Requirement 3]

[Optional: estimated time or difficulty]
```

### Step tweets (3/N to N-2)

One step per tweet:

```
(X/N) Step [number]: [Action verb] [what to do]

[Detailed instruction]

[Optional: screenshot reference or tip]

[Transition to next step]
```

**Step format rules:**
- Start with action verb (Click, Open, Navigate, Enter, etc.)
- Be specific (not "set it up" but "click Settings → API Keys")
- Include expected result ("You should see...")
- Add warnings if needed ("Don't click X yet")

### Result tweet (N-1)

Show what they achieved:

```
(N-1) That's it!

You should now have [specific result].

[Optional: verification step]

[Optional: troubleshooting tip]
```

## Transition Phrases

Use these to connect steps:

- "Next:"
- "Now:"
- "Here's where it gets important:"
- "Once that's done:"
- "After you see [X]:"
- "This is the crucial part:"

## Examples

### ✅ Good Tutorial Thread

**Example: AI Image Tutorial (Indonesian, adapted for CT)**

```
(1/n) Tutorial: How to create 4-product showcase images with AI

Perfect for crypto project marketing.

By the end, you'll have professional product grids.

Save this thread 🧵👇

---

(2/n) What you'll need:

- Midjourney account (trial works)
- 4 products to showcase
- Brief description of each

Total time: ~15 minutes

---

(3/n) Step 1: Open Midjourney Discord

Type /imagine in bot channel

Don't hit enter yet

---

(4/n) Step 2: Write base prompt

"4 panel grid layout, product showcase, clean white background, professional lighting"

This is your foundation

---

(5/n) Step 3: Add product descriptions

For each product:
"panel 1: [product 1 description]"
"panel 2: [product 2 description]"

And so on

---

(6/n) Step 4: Add style parameters

At end of prompt:
--ar 1:1 --style raw --v 6

This ensures consistency

---

(7/n) Step 5: Generate & select

Wait ~1 minute

Pick best result (U1-U4)

Not satisfied? Re-roll with 🔄

---

(8/n) Result:

You now have a 4-product grid.

Clean, professional, ready for marketing.

---

(9/n) Pro tips:

- Different categories? Add "diverse products"
- Want consistency? Use --seed [number]
- Save prompts that work

---

(10/10) That's it, fren!

You can now create product showcases for your crypto project.

Follow @handle for more crypto marketing tutorials 🫡

Retweet if helpful 🔄
```

**Why good:**
- Clear prerequisites (tweet 2)
- One action per tweet
- Specific instructions
- Crypto context (marketing)
- CT voice (fren, 🫡)
- Encouraging tone

## Type-Specific Tips

1. **Be specific:** "Click the blue button" > "Click the button"
2. **One step per tweet:** Don't cram multiple actions
3. **Show expected results:** "You should see X" after each step
4. **Add warnings:** "Don't do X before Y"
5. **Include troubleshooting:** Common errors and fixes
6. **Use visuals:** Reference screenshots when helpful
7. **Test your steps:** Make sure they actually work
8. **Crypto context:** Frame tutorial for crypto use case

## Common Mistakes

### ❌ Too vague
```
(3/N) Step 1: Set up the tool

Just configure everything and you're good to go.
```

**Why bad:** No specific actions, reader doesn't know what to do.

### ❌ Too many steps per tweet
```
(3/N) Step 1: Open settings, click API, generate key, copy it, paste in config file, save, restart app
```

**Why bad:** Overwhelming, hard to follow.

### ✅ Right level of detail
```
(3/N) Step 1: Open Settings

Click the gear icon in top right

Navigate to "API Keys" section

You should see a "Generate New Key" button
```

**Why good:** Clear action, specific location, expected result.

---

## When to Use Tutorial

**Good fit:**
- Process has clear steps (3-10 steps)
- Outcome is specific and achievable
- Reader can follow along
- Technical how-to guides for crypto

**Bad fit:**
- Concept explanation (use breakdown)
- Opinion piece (use story or breakdown)
- List of resources (use curated)
