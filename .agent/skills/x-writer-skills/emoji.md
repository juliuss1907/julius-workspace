## Usage Rules

### Frequency Guidelines

**Posts (single tweets):**
- **Optimal:** 2-5 emojis per tweet
- **Minimum:** 1 emoji (at least thread indicator or CTA)
- **Maximum:** 6 emojis (beyond this = spam)

**Threads:**
- **Optimal:** 3-6 emojis per thread (not every tweet)
- **Hook tweet:** 2-3 emojis (🧵👇 + emphasis)
- **Body tweets:** 0-1 emoji per tweet
- **Closing tweet:** 1-2 emojis (CTA)

**Articles:**
- **Optimal:** Minimal (5-10 total)
- **Headers:** 0-1 emoji per header
- **Body:** Rare (emphasis only)
- **Closing:** 1-2 emojis (CTA)

---

### Placement Strategy

**Hook/Opening (grab attention):**

✅ "🚨 Major update on X"✅ "🧠 Alpha thread incoming 🧵👇"❌ "Update on X 🎉✨🌟" (emoji spam)


**Mid-content (emphasis):**

✅ "This is the key insight 🎯"✅ "Most people miss this 👀"❌ "This is important 🔥💯✨" (too many)


**CTA (engagement):**

✅ "Retweet if helpful 🔄"✅ "Bookmark for later 🔖"✅ "Follow for more 🫡"

## Context-Dependent Usage

### Serious Topics (Minimal Emoji)

When discussing:
- Security vulnerabilities
- Regulatory issues
- Major hacks or losses

**Approach:**
- Reduce to 0-2 emojis total
- Use only 🚨 (alert) or 👀 (attention)
- Avoid hype emojis (🚀, 🔥)

**Example:**

✅ "🚨 Critical vulnerability discovered in X protocol"❌ "🚀🔥 HUGE EXPLOIT ALERT 🚨💀" (tone-deaf)


### Hype Topics (More Emoji)

When discussing:
- Major launches
- Community wins
- Memes and culture

**Approach:**
- Increase to 4-6 emojis
- Use hype emojis (🚀, 🔥, 💎)
- Match community energy

**Example:**

✅ "🚀 We're so back! New ATH incoming 🔥💎"✅ "LFG frens 🫡 wagmi 🤝"

## Emoji Combinations

### Natural Combos (Use Together)

These pairs/groups work well:

- **🧵👇** — Thread indicator (always together)
- **🧠📝** — Research/learning
- **🔥💎** — Quality + value
- **🚨👀** — Alert + attention
- **🫡🤝** — Respect + collaboration
- **⚡🚀** — Speed + launch

### Awkward Combos (Avoid)

These don't mix well:

- ❌ **💀🚀** — Death + moon (contradictory)
- ❌ **🧠💀** — Smart + ngmi (contradictory)
- ❌ **🫡💀** — Respect + death (tone clash)
- ❌ **🎉💀** — Celebration + death (tone clash)

## Emoji Anti-Patterns

### ❌ Emoji Spam

"🚀🔥💎⚡🌊 This is huge! 🚨👀🧠📝🎯"

**Why bad:** Unreadable, looks desperate.

### ❌ Emoji as Words

"I 👀 this 🔥 take and it's 💯"

**Why bad:** Harder to read, not CT style.

### ❌ Corporate Emoji Mix

"Great insights! 🌟✨🎉 Thanks for sharing! 🙏"

**Why bad:** Too corporate, not CT voice.

### ✅ Natural Emoji Usage

"🧠 Alpha thread on X protocol 🧵👇

[Thread content]

Follow for more 🫡"

**Why good:** Strategic placement, CT-appropriate, readable.

## Emoji in Different Content Types

### Posts
- **Frequency:** 2-5 per tweet
- **Types:** CT-specific + universal
- **Placement:** Hook + emphasis + CTA

**Example:**

[Content]

### Threads
- **Frequency:** 3-6 per thread
- **Types:** 🧵👇 mandatory in hook, others selective
- **Placement:** Hook (2-3) + body (0-1 per tweet) + closing (1-2)

**Example:**

(1/n) 🧠 Deep dive into X 🧵👇

(2/n) [Content - no emoji]

(3/n) Key insight 🎯

(N/N) Follow for more 🫡


### Articles
- **Frequency:** 5-10 total
- **Types:** Minimal, emphasis only
- **Placement:** Headers + key points + closing CTA

**Example:**

🧠 Understanding X Protocol

[Content]

Key Insight 🎯

[Content]

Follow @handle for more 🫡

## Platform-Specific Notes

### X (Twitter) Emoji Rendering
- All emojis render consistently
- No custom emoji support (unlike Discord)
- Emoji count toward 280 char limit (1 emoji ≈ 2 chars)

### Accessibility
- Screen readers read emoji as text
- Don't use emoji as sole information carrier
- Always have text context

**Example:**

❌ "🚨👀🔥" (no text, unclear)✅ "🚨 Major update: [text explanation]"
